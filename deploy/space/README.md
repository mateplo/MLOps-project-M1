# Adult Income Classifier — in-browser inference

Static Space generated by the CI of
[mateplo/MLOps-project-M1](https://github.com/mateplo/MLOps-project-M1) on every release tag.

- The scikit-learn pipeline (champion of the MLflow registry) is exported to **ONNX** and published
  on the Hugging Face model repo; this page downloads it and runs it with **ONNX Runtime Web**.
  No server: your inputs never leave the browser.
- The decision threshold, registry version and MLflow run_id come from `preprocess.json`,
  so the page always states exactly which model it runs.
- The same model is also served as a FastAPI microservice (Docker image on GHCR, see the repo).

**Do not edit this Space by hand**: open a pull request on GitHub instead.
